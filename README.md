# Barber App — PWA + React Native / Expo

גרסת React Native + Expo נמצאת בתיקיית [`mobile`](./mobile). גרסת ה־PWA נשארה פעילה בשורש הפרויקט כגיבוי ובשביל האתר הקיים; שתי הגרסאות משתמשות באותו Firebase ובאותה ארכיטקטורה רב־עסקית.

גרסה ראשונית של אפליקציית PWA בעברית למספרה. האפליקציה מותאמת לנייד ולמחשב, ניתנת להתקנה ממסך הבית ופועלת ללא API.

## מה כלול

- דף בית ממותג ורספונסיבי
- קביעת תור בוואטסאפ וחיוג ישיר
- מחירון שירותים ניתן לעריכה
- קטלוג מוצרים ניתן לעריכה
- גלריה עם העלאת עד 8 תמונות מהמכשיר
- קישורי ניווט ל-Waze ול-Google Maps
- עריכת שם העסק, כתובת, שעות ופרטי קשר
- שמירה מקומית בדפדפן ועבודה בסיסית במצב לא מקוון

## הרצה מקומית

נדרש Node.js 22.13 ומעלה.

```bash
npm install
npm run dev
```

## בניית גרסת Production

```bash
npm run build
```

## הערה על גרסה זו

כל התוכן נשמר רק במכשיר שבו נערך. אין עדיין משתמשים, כניסה לחשבון או סנכרון בין מכשירים. אלה ידרשו Backend או API בגרסה עתידית.
